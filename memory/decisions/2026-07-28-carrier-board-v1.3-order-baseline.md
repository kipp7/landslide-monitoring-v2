# Decision: carrier-board-v1.3-order-baseline

## Context

现场节点需要在已验证的 RK2206、DL-XLS1、CJMCU-752 和双路自动方向 RS485 模块拓扑上完成一次低风险改板，并在 2026-07-28 提交 5 片样板。设计讨论覆盖电源保护、电池采样、RS485 浪涌保护、端子并接、测试点、模块复位、机械孔、丝印和嘉立创下单工艺。

## Decision

- V1.3 继续采用 170 x 115 mm 双层模块载板，不更换已验证的 RK2206 固件引脚接口。
- 每路传感器电源增加 `MF-MSMF020-2` 可恢复保险；每路 RS485 增加 `SM712.TCT` TVS。
- 使用 PC0/ADC 采集电池电压：100k/27k 分压、1k 串联、100nF 滤波和 `BAT54S,215` 钳位。
- J6/J7 使用 `KF2EDGR-2.5-8P`，重复两组 `V+/GND/A/B`。
- `U5.7/U8.7` 现场侧地接系统 `GND`，分别连接 `D1.3/D2.3`；接受因此旁路电气隔离。
- 删除独立 TP 元件和 `SW2`，不增加 DL-XLS1 负载开关，也不增加主输入反接保护。
- 订单采用 FR-4、2 层、1.6 mm、1 oz、5 片；最后报告为白色阻焊、黑色普通丝印、有铅喷锡、过孔盖油、AOI + 飞针。

## Rationale

- 当前传感器和主控共用同一 3S 电池与系统地，直接共地符合现有线束和现场使用方式；本次优先保证接线与通信稳定，而不宣称保留隔离。
- 分路保险和 SM712 能以较小板面代价覆盖最常见的传感器短路与 RS485 瞬态风险。
- 100k/27k 分压在 12.6 V 时约输出 2.68 V，满足 3.3 V ADC 量程并保留输入余量。
- 双组端子解决单个端子只能压接一根线、多个 RS485 设备难以并接的问题。
- 电源模块已有保险且物理接口不会反接；板面紧张，负载开关和更完整的输入保护延期到有明确故障数据的后续版本。
- 用户明确选择删除测试点和 SW2，样板以当前模块化手焊维护方式为准。

## Consequences

- V1.3 的两路 RS485 不再具有端到端电气隔离；外部浪涌、地环路和雷击风险必须通过共地线束、箱外一级保护和 EVT 评估。
- 无法由 MCU 对 DL-XLS1 做独立断电恢复；无线死机仍可能需要整机重启。
- 缺少测试点会增加量产调试和故障定位难度。
- 当前订单 Gerber 是制造真值，但 14:45 的 `.epro2` 与 14:38 的原理图 PDF 早于最终补地，尚无一致的最终可编辑源文件。
- 普通 GTO 未确认包含 Logo；若厂家生产稿没有 Logo，本批白板黑字样板将不会印出该图案。

## Follow-up

- 厂家生产稿确认 Logo、板框、GPS 固定孔、安装孔和丝印方向。
- 重新导出最终 `.epro2`、原理图 PDF 和 DRC 日志，并用飞针网表核对 `U5.7/U8.7 = GND`。
- 到板后执行短路恢复、电池采样标定、双路 RS485 72 小时、温升和无线恢复 EVT。
- 室外长期版本重新评估真正隔离、SHIELD/PE、一级防雷、可配置终端和 DL-XLS1 硬复位。
