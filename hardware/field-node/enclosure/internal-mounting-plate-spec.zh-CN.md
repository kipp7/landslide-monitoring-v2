# 防水箱内安装板规格

状态：`MECH-R0.3-DRAFT / 矩形安装板试配与外围六点重选`

## 1. 设计目的

当前 IP65 防水箱内部没有高安装柱，只有若干低位孔。增加一块可拆安装板，把 PCB、电池托架、MPPT、保险和线槽统一固定到安装板，避免每个部件分别在箱底打孔。

## 2. 箱体已知尺寸

| 项目 | 尺寸 |
| --- | ---: |
| 标称外形 | 320 x 240 x 145 mm |
| 卖家图外形 | 317.9 x 238.9 x 144.6 mm |
| 底壳深度 | 约 91.1 mm |
| 盖体高度标注 | 约 53.5 mm |
| 内部多级轮廓 | 297.0109 x 218、276.0655 x 197、239.4 x 160 mm |
| 低位安装孔 | 约 `Ø2 mm` 塑料底孔，商家说明配 `M3` 自攻螺丝；孔深和是否贯通待实测 |

用户决定改用矩形安装板，避免复刻箱体异形轮廓。`276.0655 x 197 mm` 仍是卖家图中的名义参考包络，不能按零间隙直接作为成品尺寸；注塑箱体、FR4 CNC 和装配姿态均存在公差。

## 3. 安装板初始规格

- `MECH-R0.3-DRAFT` 首件试配尺寸：`272 x 193 x 3 mm`，相对 `276.0655 x 197 mm` 名义包络四周约留 2 mm。
- 首选材料：FR4/G10 阻燃环氧玻纤板，建议自然色或黑色，边缘倒钝。
- 首件先用透明 PET/PP 或廉价板材验证能否倾斜放入、平放和取出；通过后才把该矩形冻结为 FR4 成品外形。
- 四角建议 `R3-R5` 或 `2 x 45 deg` 倒角，并去毛刺；若实际弧形槽仍侵入板平面，只在干涉点追加局部避让，不恢复整圈异形仿形。
- 不采用 `276.0655 x 197 mm` 零间隙成品板。若首件仍偏紧，长宽各再缩小 1-2 mm，而不是强压入箱体。
- 板面不得遮挡箱盖螺钉、密封槽、透气阀和底部格兰头操作区。

备选材料是 `2 mm 5052` 铝板。采用铝板时必须：

- 在 DL-XLS1/GPS 天线投影区开窗或把天线伸出金属板边缘。
- 对板边去毛刺并做绝缘隔离。
- 明确铝板与 PE/屏蔽地的连接，不能偶然接触逻辑 GND。

## 4. 与箱体连接

优先级如下：

1. 现有孔确认为 `M3` 自攻螺丝底孔且为盲孔：选 6 个分布均匀的孔；安装板加工 `Ø3.5 mm` 通孔，使用限深 `M3` 自攻螺丝和平垫固定，FR4 直接承托在共面的塑料柱顶。自攻螺丝只咬合箱体塑料柱，不在 FR4 上攻螺纹。
2. 现有孔无螺纹但可装热熔/压入螺母：必须确认箱体材料和底厚，避免热损伤、开裂或穿底。
3. 现有孔为贯通孔：不直接使用普通螺钉；改用 EPDM 密封垫圈 + 密封螺钉 + 外部封帽，或使用箱内粘接式螺柱。
4. 现有孔不可用：使用与箱体材料兼容的粘接式 M4 底座螺柱，不在密封底面新增孔。

所有方案都必须经过拉力、冷热循环和喷水测试。普通双面胶、热熔胶和包装泡沫不作为永久结构固定。

箱体塑料自攻孔不作为日常维护螺纹。装配时控制扭矩且避免反复拆装；PCB、充电板和线槽均从安装板正面独立拆卸，正常维护不拆安装板。

### 4.1 六点支撑决定

六孔是“FR4 主安装板到箱体”的专用锚固孔，不是 PCB、充电模块、电池托架或倾角钢板的安装孔。它们限制安装板的 X/Y 位移和抬起，并用中间一列抑制 3 mm FR4 长边弯曲。

`MECH-R0.2-DRAFT` 在较小内区选定的旧 P1-P6 仅保留为历史参考；其定位图见 [`assets/08-enclosure-six-boss-selection.png`](assets/08-enclosure-six-boss-selection.png)，不得继续作为扩大矩形板的加工孔位。新板按以下规则重选六点：

- 将实物照片顺时针旋转，使箱体长边水平；从上、下两排外围低位塑料柱各选左、中、右三点，形成“3 列 x 2 行”宽支撑多边形。
- 新六点暂编号 `R1-R6`：`R1/R2` 为左列上/下，`R3/R4` 为中列上/下，`R5/R6` 为右列上/下。准确实物柱号和坐标必须在试配板上转印后冻结。
- 不使用四角、四边中央的大型黄铜箱盖螺柱；不使用紧贴侧壁的外圈低柱。
- 六点组成的支撑多边形覆盖主要载荷区。板上电池、PCB 和倾角局部基准板必须布置在该多边形内或紧邻其边界，长边未支撑端只允许布置轻型线槽和线束。
- 照片有透视畸变，图中像素位置不得换算成 CNC 坐标，也不得根据板长宽反推孔坐标。

当前六点直接承托切面见 [`assets/10-m3-fr4-coplanar-boss-section.svg`](assets/10-m3-fr4-coplanar-boss-section.svg)。外围柱从主箱底到柱顶约 6 mm；中间四柱位于 1 mm 加高层上，柱身约 5 mm，因此总柱顶标高同为约 6 mm。FR4 直接放在柱顶，不增加 1 mm 高度垫片。若所选柱确认是 M3 自攻盲孔，FR4 加工 `6 x Ø3.5 mm` 通孔；M3 自攻螺钉长度和有效咬合深度必须按 R1-R6 实测后冻结。旧 [`assets/09-m3-fr4-boss-section.svg`](assets/09-m3-fr4-boss-section.svg) 的隔离套结构仅保留为 `MECH-R0.2-DRAFT` 历史。

## 5. 板上安装

- 现场节点 PCB：`170 x 115 mm`，4 x M3，孔中心距 PCB 边 3.5 mm。
- PCB 使用 `8-10 mm` M3 支柱，底面不得接触安装板。
- 电池使用独立阻燃托盘和两条绑带，托盘固定到安装板。
- 当前照片估算电池包络约 `70 x 55 x 40 mm`，仅用于布局预留；正式托盘仍需卡尺实测长、宽、高、圆角和出线位置。
- 太阳能充电板、充电支路保护和可插拔电池连接器位于太阳能/电池线束入口附近，远离 GPS/DL-XLS1。当前载板已有负载开关，不重复安装外置负载开关。
- 倾角变送器只有在安装板和箱体共同构成可靠测量基准时才可固定在板上；否则单独固定到外部监测基准。
- 外部端子方向朝向箱体下侧格兰头，留出线弯曲和端子操作空间。

## 6. 孔位获取方法

正式 DXF 前先制作一块 `272 x 193 mm` 的透明 PET/PP 片或硬纸样板：

1. 样板放入箱内，确认四边和四角均有可见间隙，能够不刮擦侧壁地平放和取出；只对实际干涉点追加局部避让。
2. 从上、下外围低柱各选左、中、右三点并转印为 `R1-R6`；若任一柱破损或高度异常，重新评审整组六点。
3. 以安装板左下角为 `(0,0)`，测量 R1-R6 的 X/Y 坐标，精度至少 0.5 mm；另以 R1 为复核原点记录相对孔距。
4. 逐个测量 R1-R6 的柱顶高度、孔径、有效深度，并确认是盲孔还是贯通孔。
5. 用直尺跨放六个柱顶检查共面性；最大高度差超过 `0.5 mm` 时使用定制等高隔离套补偿，不允许靠拧紧螺钉拉平 FR4。
6. 测量底面到合盖后最低结构的净高。
7. 依据实测生成安装板 DXF、R1-R6 孔表和装配图。

## 7. 验收

- 安装板可在不拆密封圈的情况下装入和取出。
- 六个固定点全部锁紧后，板面无明显翘曲。
- 设备总成承受运输振动和任意方向 50 N 拉力后不位移。
- 螺钉未穿透未知薄壁，箱体无应力白化或裂纹。
- IP65 喷水测试后所有箱底固定点无渗水。
- PCB、端子、保险和电池均可独立维护，不需要拆除倾角基准件。

## 8. 倾角传感器刚性基准

当前倾角变送器机械接口已由手册冻结：外形 `90 x 58 x 36 mm`，4 x `Ø3.6 mm` 安装孔，孔距 `78 x 39 mm`。以传感器底座左下角为 `(0,0)`，四孔中心为 `(6,9.5)`、`(84,9.5)`、`(6,48.5)`、`(84,48.5)` mm。其读数代表传感器安装面的姿态，不应依赖塑料箱壁、FR4 安装板或可蠕变的胶垫作为测量基准。

现场长期版优先将倾角传感器移到监测桩/被测结构的独立金属基准件。为保持比赛样机外观和装配一致性，当前比赛版允许传感器留在防水箱内，但必须使用独立金属小基准板，不能直接安装到 FR4：

- 主安装板继续使用 3 mm FR4/G10，承载 PCB、电池、充电模块和线槽。
- 倾角传感器单独使用约 `120 x 85 x 3 mm` 的 304 不锈钢板；更轻的备选是 `120 x 85 x 4 mm` 5052 铝板。
- 金属小板加工 4 x M3 螺纹孔承接传感器。若 `120 x 85 mm` 小板与传感器同心，四个螺纹孔中心相对小板左下角为 `(21,23)`、`(99,23)`、`(21,62)`、`(99,62)` mm。小板自身另设 4 个安装孔固定到 FR4，禁止单边悬臂；这 4 个板间固定孔需要结合箱体支撑位置确定。
- FR4 在倾角小板下方增加 4 个刚性隔离柱/支撑点，并尽量落在箱体现有塑料孔柱附近，减少 FR4 局部弯曲。
- 箱体外部使用上下两组抱箍或四点背架固定；比赛搬运后重新校零并检查扭矩标记。
- 整块 `265 x 185 x 3 mm` 普通钢板约重 1.16 kg，不采用整块铁底板，以免塑料自攻柱长期受载，同时避免大面积金属影响 GPS/DL-XLS1 天线。

现场长期版结构仍为：

- 传感器直接用 4 x M3 螺钉固定到平整的 304 不锈钢基准板，建议板厚 3 mm；备选 4 mm 阳极氧化 5052 铝板。
- 基准板与监测桩使用刚性角码/槽钢连接；圆杆使用上下两组 U 型抱箍，轴向间距建议不小于 150 mm，并设置防转结构。
- 防水箱可以安装在同一外部背架上，但箱体塑料和 FR4 不进入倾角传力路径。
- 不在传感器与基准板之间垫普通橡胶、泡棉或厚胶层；安装面需要平整、贴合并在现场校零。
- 传感器为 IP65，外置时增加遮阳防雨罩，电缆出口朝下形成滴水弯。
